# Myrkwood: Offshoot (v10)
Hello all once again, this is another update that adds content that I felt would make the game feel more fun.

# Changes: 
- Added 23 achievements on Steam. 
- Made maps slightly bigger.
- Made it so Solmere can appear on your Main Menu when you select it.
- Added 7 new armors.
- Added an extra new item slot.
- Hopefully fix players not healing in a multiplayer match as a client.
- Added a tutorial for those that don't know how to play the game, this appears on Defense.
- Added a new enemy type: Golems, non-hostile enemies that only provide benefits to other enemies. The first variant is the Protector Golem, which goes in range of another enemy and will make it invincible (doesn't work on Bombrats or other Golems).
- Added a Jumper Slime, which throws out stars when it lands.
- Added a Bestiary which gives descriptions & also developer commentary on enemies.
- Redo Dungeon waves to have some cohesion.
- Fixed the bounds of the barriers being slightly off.
- Added a splatter lifetime.
- Removed most delays from Dungeons improving the flow significantly.
- Enemies won't spawn on top of each other making it fly off screen.
- The main menu logo is once again moved a bit.
- Change the look of some tiles.
- Ghosts no longer damage players and deal Weak, which halves your damage output.
- Added a last life indicator on Dungeons.
- Removed a jittering thing that appears when walking diagonally.
- Added an expected bombrat count to Defense.
- Allowed players to spam certain weapons again.
- Updated to Godot Engine 4.6.1
- Upgrades now say your current level.
- Added explanations for game modes saying what you're supposed to do.
- You now gain gold for completing a room/wave.
- You now get healed every room in Dungeons.
- Dungeons doesn't override starting the game to do a custom scene.
- Added y-sort in some places.
- Natural regeneration doesn't block taking damage for 5 seconds.
- Enemies on Defense spawn a little offset.
- Fixed a crash where the game would crash after killing a Poison Slime while having Poison from the very same slime.
